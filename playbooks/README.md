# Playbooks

Paper-based investigation playbooks, written from my own study notes.

These are not lab-tested yet. My lab hardware is limited (running Wazuh,
Windows, and Kali together pushes my laptop's CPU and cooling too hard),
so I wrote these as theory first. Real lab results live in `investigations/`.

Each playbook has: alert, triage questions, investigation steps,
containment, and evidence to keep. A "Lab validation" section will be
added once I run the scenario in my lab.
